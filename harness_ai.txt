===========================
   What AIDA Reads to Discover Workflows

   1. description — most important field

   metadata:
     description: >
       Migrates a Jenkins pipeline to Harness. Detects stack type from hoover.yaml,
       converts using AI, runs validation, and marks the pipeline as migrated on success.
       Use this when your team has a Jenkins pipeline that needs to move to Harness CI/CD.

   Write it like you're answering: "When should I use this workflow?"
   AIDA uses this to match against user queries like "I want to migrate a Jenkins pipeline."

   ---
   2. name — plain English, not an identifier

   # Bad — hard for AI to match
   name: harness-idp-jenkins-conv-wf-02

   # Good — AIDA can match "migrate jenkins" or "convert pipeline"
   name: Migrate Jenkins Pipeline to Harness

   ---
   3. tags — categorisation signals

   metadata:
     tags:
       - migration
       - jenkins
       - ci-cd
       - self-service
   AIDA uses tags to group and filter workflows in response to category questions like "show me all migration workflows."

   ---
   4. Parameter descriptions — help AIDA suggest inputs

   parameters:
     properties:
       sysId:
         title: SYSID
         description: Your application SYSID (e.g. SYSID-06534). Found in Jarvis.
       pipelineName:
         title: Jenkins Pipeline Name
         description: The name of the Jenkins pipeline you want to migrate.
   When a user asks AIDA to run the workflow, it reads these descriptions to prompt the user for the right inputs.

   ---
   5. TechDocs (optional — but enables semantic search)

   If you write a docs/index.md for the workflow and link it in catalog-info.yaml, the TechDocs semantic search can answer deep questions:
   "How does the Jenkins migration workflow handle Groovy shared libraries?"
   This requires the IDP_TECH_DOCS_SEMANTIC_SEARCH feature flag to be on.

   ---
   Summary — What to Write, What to Skip

   ┌───────────────────────┬───────────────────────────────────────────────┬────────────────────────────────────────┐
   │         Field         │                  Write this                   │                  Why                   │
   ├───────────────────────┼───────────────────────────────────────────────┼────────────────────────────────────────┤
   │ name                  │ Plain English, action-verb first              │ AIDA matches against it                │
   ├───────────────────────┼───────────────────────────────────────────────┼────────────────────────────────────────┤
   │ description           │ "Use this when…" + what it does               │ Primary discovery signal               │
   ├───────────────────────┼───────────────────────────────────────────────┼────────────────────────────────────────┤
   │ tags                  │ 3-5 relevant keywords                         │ Grouping + filtering                   │
   ├───────────────────────┼───────────────────────────────────────────────┼────────────────────────────────────────┤
   │ Parameter description │ What the input is + where to find it          │ AIDA suggests inputs to user           │
   ├───────────────────────┼───────────────────────────────────────────────┼────────────────────────────────────────┤
   │ TechDocs              │ How-to guide                                  │ Semantic search (needs FF)             │
   ├───────────────────────┼───────────────────────────────────────────────┼────────────────────────────────────────┤
   │ Step name             │ Clear action: "Fetch Jenkinsfile from GitHub" │ Shown in execution view + AI summaries │
   └───────────────────────┴───────────────────────────────────────────────┴────────────────────────────────────────┘

   ---
   You Don't Need To

   - Repeat information that's in the catalog entity (AIDA reads both)
   - Write a separate AI config or prompt file
   - Register anything special — AIDA reads all registered workflows automatically

   The rule: treat description like documentation for a colleague who has never seen the workflow. If they could find the right workflow from the description alone, AIDA can too.
